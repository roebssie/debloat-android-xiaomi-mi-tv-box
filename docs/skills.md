# Skills demonstrated

- Wireless ADB over a local network: connect, inspect, install, reboot, capture screenshots, and verify activity state.
- Android launcher development: HOME intent handling, boot receiver behavior, screensaver integration, focus navigation, and remote-key handling.
- Android TV performance work: keep the launcher lightweight, avoid unnecessary foreground activities, and leave AirPlay as a background service.
- Canvas UI rendering: anti-aliased icons, glass panels, shadows, focus transitions, live clock hands, weather icons, and smooth scrolling text.
- Media integration: inspect active media sessions and distinguish Spotify playback from audio-only AirPlay.
- Device QA: reboot verification, package checks, app return paths, logcat checks, activity/task inspection, and visual screenshot review.

These notes describe the practical work in this project without publishing private device details or credentials.
